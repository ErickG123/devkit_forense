# Security Policy

## Supported Versions

Currently, only the latest release of ForenseLab is supported with security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them by using GitHub Security Advisories for this repository, or by contacting the maintainers directly via email. 

We will review your report and respond as quickly as possible with next steps and an expected timeline for a patch.
